# LocalReviewer

Локальное десктопное приложение для поштучного ревью и разметки кейсов.

## Возможности

- Импорт файлов: `.xlsx`, `.csv`, `.json`, `.jsonl`
- Гибкий маппинг колонок при импорте
- Режим ревью: один кейс на экране
- Статусы: Хорошо / Плохо / Сомневаюсь / Дубль / Пропустить
- Комментарии и шаблоны комментариев
- Теги (системные и пользовательские)
- Фильтры по статусам, файлам, тегам, автопроверкам, тексту
- Автоматические проверки (пустой текст, ссылки, телефоны, дубли и т.д.)
- Табличный режим с выбором столбцов и фильтрацией
- История изменений
- Отчёты с графиками и экспорт в Excel
- Резервное копирование
- Чёрно-зелёная тема интерфейса

## Установка

1. Установите Python 3.11+
2. Создайте виртуальное окружение:
python -m venv venv
venv\Scripts\activate
3. Установите зависимости:
pip install -r requirements.txt
## Запуск
python main.py

## Технологии

- Python 3
- PySide6 (Qt)
- SQLite (встроен в Python)
- openpyxl (Excel)
- matplotlib (графики)

## Лицензия

Проект создан для личного использования.
