# 🟩 Local Reviewer

**Локальное десктоп-приложение для поштучного ревью и разметки датасетов.**
Без интернета, без облака, без LLM — все данные остаются на вашем ПК.

Приложение для тех, кто вручную проверяет качество ответов моделей и запросов:
загрузили файл → настроили колонки → размечаете кейсы по одному → получили отчёты и готовый файл разметки.

## ✨ Возможности

### 📥 Импорт
- Форматы: `.xlsx`, `.csv`, `.json`, `.jsonl`
- Гибкий маппинг колонок: «Запрос», «Ответ модели», «Номер обращения», «Продукт», «Ответ оператора», «Группа» и др.
- Превью данных, выбор листа и строки заголовка перед импортом
- Исходные файлы **никогда не изменяются**

### 🔍 Ревью
- Режим «один кейс на экране» — ничего не отвлекает
- Табличный режим: пагинация, выбор столбцов, фильтр по значениям столбца (например, по «Продукту»)
- Статусы: ✅ Хорошо · ❌ Плохо · ❓ Сомневаюсь · 🔄 Дубль · ⏭️ Пропустить
- Комментарии с быстрыми шаблонами (свои шаблоны можно добавлять и удалять)
- Теги: системные и пользовательские, раскрывающаяся панель
- Автопроверки: пустой/короткий/длинный текст, ссылки, email, телефоны, дубли, CAPS и др.
- Фильтры: статус, файл, теги, комментарий, автопроверки, текстовый поиск
- Горячие клавиши для быстрой разметки

### 📈 Аналитика
- Отчёты: общий, по файлам, по тегам, по автопроверкам
- Прогресс-бар разметки и графики (статусы, прогресс по файлам, топ тегов)
- Анализ конкретного файла или всего проекта
- Экспорт результатов и отчётов в `.xlsx`

### 💾 Надёжность
- Хранение в SQLite — одна папка проекта на диске
- Резервные копии: создание, восстановление, удаление
- История изменений по каждому кейсу
- Автосохранение каждого действия

## 🚀 Установка

### Вариант 1 — Готовая сборка (Windows)
1. Скачайте папку `LocalReviewer` со сборкой.
2. Запустите `LocalReviewer.exe`. (папка dist)
3. Установка, интернет и регистрация не нужны.

### Вариант 2 — Из исходников
Требуется **Python 3.11+** и Windows 10/11.

```bash
git clone https://github.com/Rhun96/LocalReviewer.git
cd LocalReviewer
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py

Быстрый старт
Создайте проект — кнопка «Создать проект», выберите папку.
Загрузите файл — «Добавить файл», настройте маппинг колонок.
Размечайте — «Начать ревью»: статусы клавишами 1–5, комментарии, теги.
Смотрите аналитику — «Отчёты»: прогресс, графики, статистика.
Выгружайте результат — экспорт готовой разметки в .xlsx.

🗄️ Хранение данных
Проект — это обычная папка на вашем ПК:

MyProject/
├── project.sqlite   # вся разметка: статусы, комментарии, теги, история
└── backups/         # резервные копии базы

🔧 Сборка в .exe
pip install pyinstaller
pyinstaller --noconfirm --onedir --windowed --name LocalReviewer main.py

Готовая сборка появится в dist/LocalReviewer/ — папку можно переносить на любой ПК с Windows.
