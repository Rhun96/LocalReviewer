# 🟩 Local Reviewer

**Локальное десктоп-приложение для ручного ревью, разметки и регрессионного тестирования датасетов.**
Без интернета, без облака, без LLM — все данные остаются на вашем ПК.

Загрузили файл → настроили колонки → размечаете кейсы по одному или пачками →
фиксируете версию датасета → импортируете прогоны модели → сравниваете ответы →
гоняете регрессию перед релизом → выгружаете отчёт.

📖 **Подробная инструкция по всем функциям: [docs/USER_GUIDE.md](docs/USER_GUIDE.md).**

## ✨ Возможности

### 📥 Импорт
- Форматы: `.xlsx`, `.ods`, `.csv` (кодировка и разделитель на выбор), `.json`, `.jsonl`
- Гибкий маппинг колонок: «Запрос», «Ответ модели», «Номер обращения», «Продукт»,
  «Ответ оператора», «Группа», «Идентификатор», «Источник (ссылка на БЗ)» и др.
- Свои категории маппинга — значения попадают в метаданные и становятся столбцами таблицы
- Превью с примерами значений, выбор листа и строки заголовка
- Предимпортная проверка: покрытие ID, дубли, пустые запросы — с подтверждением
- Дедуп повторных импортов, отчёт о битых строках, исходные файлы **никогда не изменяются**
- Импорт в фоне с прогрессом и отменой

### 🔍 Ревью
- Режим «один кейс на экране» + табличный режим: пагинация, выбор столбцов,
  фильтр по значениям столбца, сортировка, колонка ⚠ со сводкой автопроверок
- Статусы из активного профиля + строгий режим «Плохо» (комментарий → причина,
  без них с кейса не уйти; таблица и фильтры доступны)
- Массовые операции: статус/комментарий/теги/«просмотрено»/проверки пачкой,
  прогресс, отмена с откатом, отмена последней операции
- Умная очередь: обычная, непроверенные, проблемные; настраиваемые веса и переход
- Комментарии с шаблонами: переменные (`{product}`, `{case_id}`…), привязка к причине
- Теги: системные и свои (+ создание прямо из ревью)
- ⚠ Таксономия ошибок: категории → подкатегории → критичность; редактор с архивом
- Вердикты автопроверок ✓/✗ с precision правил в отчётах
- 🔍 Похожие кейсы (TF-IDF, без LLM) и 👯 поиск дублей — только контекст, без авторазметки
- 📋 Профили ревью: свои коды статусов с base-семантикой, хоткеи, обязательные поля
- Фильтры: статус, файл, теги, комментарий, проверки, severity, причина, поиск;
  сохранённые фильтры с видом таблицы (колонки, сортировка, очередь)
- «🏁 Завершить ревью» при 100% разметке → версия датасета
- Горячие клавиши из профиля (не срабатывают при вводе текста)

### 🗂 Датасеты, прогоны, регрессия
- Версии датасетов: полные слепки (статусы, причины, теги), freeze эталона,
  сравнение по ID (изменения/конфликты), типы working/golden/test/safety/archive
- 🏃 Прогоны модели: импорт ответов, сопоставление по ID/промпту, сравнение
  ответов рядом (вердикт + ранги, absolute отдельно), своя разметка ответов
- 🧪 Регрессия: baseline (frozen-версия или прогон) vs кандидат, матрица
  Good→Bad, gate ✅ PASS / ❌ FAIL, фильтры, экспорт `regressions.xlsx`

### Баги и обмен разметкой (V2)
- Bug Report из кейса и из регрессии, связь баг-кейс, Copy Jira/Markdown/Plain
- History Search + Visual Diff ответов
- Annotation IO: JSONL, Merge/Update/Preview; экспорт контекста кейса (MD/Plain)
- Подсказки категорий и похожих, вкладка «Личное»

### 🤖 Автопроверки (Rules Engine)
- Пустой/короткий/длинный текст, URL, email, телефоны, дубли, CAPS, повторы
  слов и символов, серии `?!`, длинные предложения, служебный мусор (`SYSTEM:`),
  HTML, Markdown, битая кодировка, невидимые символы
- Уровни: 🔴 error · 🟡 warning · 🔵 info; каждое правило включается отдельно
- Живые проверки в кейсе + «Пересчитать проверки» в БД (с прогрессом и отменой)
  для фильтров, очереди и таблицы

### 📈 Аналитика
- Отчёты: общий, по файлам, по тегам, по автопроверкам; графики под тему оформления
- Статистика в скоупе файла или всего проекта
- Экспорт результатов и отчётов в `.xlsx` (защита от formula injection)

### 💾 Надёжность
- Хранение в SQLite — одна папка проекта на диске, версионированные миграции (v17)
  с autobackup и аккуратным слиянием дублей старых импортов
- Резервные копии через SQLite backup API с проверкой целостности и ротацией
- История изменений по каждому кейсу, включая массовые операции и вердикты
- Тяжёлое (импорт/экспорт/пересчёт/бэкап/поиск дублей) — в фоне, интерфейс не виснет

### 🎨 Оформление
- Fluent-дизайн (Windows 11): светлая, тёмная и системная темы, переключаются
  в Настройках без перезапуска; без библиотеки — классическая тема

## 🚀 Установка

### Вариант 1 — Готовая сборка (Windows)
1. Скачайте `LocalReviewer-win64.zip` из раздела Releases.
2. Распакуйте и запустите `LocalReviewer.exe`.
3. Установка, интернет и регистрация не нужны.

### Вариант 2 — Из исходников
Требуется **Python 3.11+** и Windows 10/11.

```bash
git clone https://github.com/Rhun96/LocalReviewer.git
cd LocalReviewer
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Быстрый старт
1. Создайте проект — кнопка «Создать проект», выберите папку.
2. Загрузите файл — «Добавить файл», настройте маппинг колонок.
3. Размечайте — «Начать ревью»: статусы клавишами из профиля (по умолчанию 1–5),
   комментарии, теги, причины ошибок;
   или таблицей пачкой через «☑ Выбрать все по фильтру».
4. Нажмите «🔄 Пересчитать проверки», чтобы заработали очередь «Проблемные»,
   фильтры по автопроверкам и колонка ⚠.
5. Смотрите аналитику — «Отчёты»: прогресс, графики, статистика.
6. Выгружайте результат — экспорт готовой разметки в .xlsx.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| 1 | Статус «Хорошо» |
| 2 | Статус «Плохо» |
| 3 | Статус «Сомневаюсь» |
| 4 | Статус «Дубль» |
| 5 | Статус «Пропустить» |
| ← / → | Предыдущий / следующий кейс |

## 🗄️ Хранение данных
Проект — это обычная папка на вашем ПК:

```
MyProject/
├── project.sqlite   # вся разметка: статусы, комментарии, теги, история
├── backups/         # резервные копии базы
└── logs/            # логи приложения
```

Старые проекты мигрируются автоматически при открытии (с autobackup).

## 🔧 Сборка в .exe

```bash
pip install -r requirements-dev.txt
pyinstaller LocalReviewer.spec --noconfirm
```

Готовая сборка появится в `dist/LocalReviewer/` — папку можно переносить на любой ПК
с Windows. Для релиза: поставьте тег `v*` — GitHub Actions соберёт
`LocalReviewer-win64.zip` автоматически (см. `.github/workflows/release.yml`).
