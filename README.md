# 🟩 Local Reviewer — 0.3

**Локальное десктоп-приложение для поштучного ревью и разметки датасетов.**
Без интернета, без облака, без LLM — все данные остаются на вашем ПК.

Загрузили файл → настроили колонки → размечаете кейсы по одному или пачками →
смотрите аналитику → фиксируете версию датасета → выгружаете готовый файл разметки.

## ✨ Возможности

### 📥 Импорт
- Форматы: `.xlsx`, `.csv` (кодировка и разделитель на выбор), `.json`, `.jsonl`
- Гибкий маппинг колонок: «Запрос», «Ответ модели», «Номер обращения», «Продукт»,
  «Ответ оператора», «Группа», «Идентификатор», «Источник (ссылка на БЗ)» и др.
- Свои категории маппинга — значения попадают в метаданные и становятся столбцами таблицы
- Превью данных, выбор листа и строки заголовка перед импортом
- Дедуп повторных импортов, отчёт о битых строках, исходные файлы **никогда не изменяются**

### 🔍 Ревью
- Режим «один кейс на экране» + табличный режим: пагинация, выбор столбцов,
  фильтр по значениям столбца, колонка ⚠ со сводкой автопроверок
- Статусы: ✅ Хорошо · ❌ Плохо · ❓ Сомневаюсь · 🔄 Дубль · ⏭️ Пропустить
- Массовые операции: галочки, «выбрать все по фильтру», статус/тег/комментарий
  пачкой, подтверждение и отмена последней операции
- Умная очередь: обычная, непроверенные, проблемные (по severity автопроверок)
- Комментарии с быстрыми шаблонами (свои шаблоны можно добавлять и удалять)
- Теги: системные и пользовательские, раскрывающаяся панель
- ⚠ Таксономия ошибок: категории → подкатегории → критичность; быстрый выбор
  причины после «Плохо», редактор таксономии прямо из ревью
- 📋 Профили ревью: свои схемы статусов, горячие клавиши, обязательные поля
- 🗂 Версии датасетов: слепки статусов (целиком или из файла), freeze эталона,
  сравнение версий по ID, кнопка «🏁 Завершить ревью» при 100% разметке
- Фильтры: статус, файл, теги, комментарий, автопроверки, текстовый поиск;
  фильтры можно сохранять и переиспользовать
- Горячие клавиши для быстрой разметки (не срабатывают при вводе текста)

### 🤖 Автопроверки (Rules Engine)
- Пустой/короткий/длинный текст, URL, email, телефоны, дубли, CAPS, повторы
  слов и символов, серии `?!`, длинные предложения, служебный мусор (`SYSTEM:`),
  HTML, Markdown, битая кодировка, невидимые символы
- Уровни: 🔴 error · 🟡 warning · 🔵 info; каждое правило включается отдельно
- Живые проверки в кейсе + «Пересчитать проверки» в БД (с прогрессом и отменой)
  для фильтров, очереди и таблицы

### 📈 Аналитика
- Отчёты: общий, по файлам, по тегам, по автопроверкам; графики под тему оформления
- Статистика в скоупе файла или всего проекта
- Экспорт результатов и отчётов в `.xlsx` (защита от formula injection)

### 💾 Надёжность
- Хранение в SQLite — одна папка проекта на диске, версионированные миграции (v8)
  с autobackup и аккуратным слиянием дублей старых импортов
- Резервные копии через SQLite backup API с проверкой целостности и ротацией
- История изменений по каждому кейсу, включая массовые операции
- Тяжёлое (импорт/экспорт/пересчёт/бэкап) — в фоне, интерфейс не виснет

### 🎨 Оформление
- Fluent-дизайн (Windows 11): светлая, тёмная и системная темы, переключаются
  в Настройках без перезапуска; без библиотеки — классическая тема

## 🚀 Установка

### Вариант 1 — Готовая сборка (Windows)
1. Скачайте `LocalReviewer-win64.zip` из раздела Releases.
2. Распакуйте и запустите `LocalReviewer.exe`.
3. Установка, интернет и регистрация не нужны.

### Вариант 2 — Из исходников
Требуется **Python 3.11+** и Windows 10/11.

```bash
git clone https://github.com/Rhun96/LocalReviewer.git
cd LocalReviewer
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Быстрый старт
1. Создайте проект — кнопка «Создать проект», выберите папку.
2. Загрузите файл — «Добавить файл», настройте маппинг колонок.
3. Размечайте — «Начать ревью»: статусы клавишами 1–5, комментарии, теги;
   или таблицей пачкой через «☑ Выбрать все по фильтру».
4. Нажмите «🔄 Пересчитать проверки», чтобы заработали очередь «Проблемные»,
   фильтры по автопроверкам и колонка ⚠.
5. Смотрите аналитику — «Отчёты»: прогресс, графики, статистика.
6. Выгружайте результат — экспорт готовой разметки в .xlsx.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| 1 | Статус «Хорошо» |
| 2 | Статус «Плохо» |
| 3 | Статус «Сомневаюсь» |
| 4 | Статус «Дубль» |
| 5 | Статус «Пропустить» |
| ← / → | Предыдущий / следующий кейс |

## 🗄️ Хранение данных
Проект — это обычная папка на вашем ПК:

```
MyProject/
├── project.sqlite   # вся разметка: статусы, комментарии, теги, история
├── backups/         # резервные копии базы
└── logs/            # логи приложения
```

Старые проекты мигрируются автоматически при открытии (с autobackup).

## 🔧 Сборка в .exe

```bash
pip install -r requirements-dev.txt
pyinstaller LocalReviewer.spec --noconfirm
```

Готовая сборка появится в `dist/LocalReviewer/` — папку можно переносить на любой ПК
с Windows. Для релиза: поставьте тег `v0.3.0` — GitHub Actions соберёт
`LocalReviewer-win64.zip` автоматически (см. `.github/workflows/release.yml`).
